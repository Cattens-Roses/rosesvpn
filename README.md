# baseapp

A small, reusable desktop application shell built with Rust and GPUI. It includes a Home screen,
an Appearance settings page, and the shared UI components and themes in `crates/ui`.

## Run

```sh
cargo run -p baseapp
```

## Verify

```sh
cargo check -p baseapp
```
